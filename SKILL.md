# PetMemeGenerator

## Overview

PetMemeGenerator is an AI skill that transforms user's pet photos into meme stickers.

The workflow:

1. Analyze uploaded pet image
2. Extract pet subject
3. Preserve pet identity
4. Apply meme template
5. Generate sticker image

---

# Core Principle

The generated sticker must always preserve the original pet identity.

Maintain:

- animal species
- fur color
- fur pattern
- eye color
- ear shape
- face characteristics

---

# Forbidden Changes

Never generate:

- different animal species
- extra eyes
- extra ears
- extra limbs
- duplicated pets
- distorted face

---

# Generation Workflow

## Step 1

Analyze uploaded pet image.

Identify:

- pet type
- color
- unique markings
- pose
- facial features


## Step 2

Remove background and isolate pet.


## Step 3

Place pet into selected meme template.


## Step 4

Export final sticker format.

---

# Output Requirement

Default output:

- PNG
- sticker style
- transparent background when possible
- suitable for messaging apps
